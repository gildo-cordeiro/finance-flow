# Architecture Decision Records (ADRs)

Este diretório contém os Architecture Decision Records (ADRs), que são documentos curtos focados em registrar decisões arquiteturais e de produto importantes tomadas ao longo do projeto.

## Como criar um novo ADR

1. Copie um arquivo existente ou crie um novo incrementando o número no padrão `NNNN-slug-em-kebab-case.md`.
2. Preencha o status, a data em que a decisão foi implementada, o contexto (problema) e a decisão tomada.
3. Não esqueça de citar evidências (issues, PRs, ou hashes de commits) e listar as consequências da decisão.
4. Adicione o novo ADR ao índice abaixo.
